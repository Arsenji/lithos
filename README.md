# LITHOS

Каталог украшений из натуральных камней. Сайт показывает модели и открывает заявку в Telegram. Оплаты, корзины и оформления заказа на сайте нет.

Рабочее приложение — Next.js в `src/`. Файлы `index.html`, `css/`, `js/` и `assets/` — предыдущий статический прототип брендбука. Их не открывает `npm run dev`.

## Установка и запуск

Нужны Node.js 22 и npm.

```bash
cp .env.example .env.local
npm install
npm run dev
```

Сайт откроется на [http://localhost:3000](http://localhost:3000).

```bash
npm run build
npm start
npm run lint
```

## Переменные

| Переменная | Где используется | Назначение |
| --- | --- | --- |
| `NEXT_PUBLIC_TELEGRAM_BOT_USERNAME` | клиент | Имя бота без `@`. Пока пусто, кнопки не ведут на чужой аккаунт и пишут, что канал ещё не подключён. |
| `NEXT_PUBLIC_SITE_URL` | сервер и метаданные | Канонический адрес для sitemap и Open Graph. |
| `TELEGRAM_BOT_TOKEN` | только сервер, позже | Токен бота. В клиентский код не попадает. |
| `TELEGRAM_LEADS_CHAT_ID` | только сервер, позже | Закрытый чат, куда бот отправит заявку. |
| `NEXT_PUBLIC_YANDEX_METRIKA_ID` | клиент, после согласия | Счётчик Метрики. Пока переменной нет, события не отправляются. |

## Данные каталога

- Коллекции: `src/data/collections.ts`
- Изделия: `src/data/products.ts`
- Скрытые позиции: `isActive: false`. Они не попадают в каталог, sitemap и страницу модели.
- Цена в данных — ориентир. Перед публикацией замените её на согласованную.
- Фото: `public/images/`. Тип `actual` — реальная съёмка. Тип `concept` показывает бейдж «Концептуальная визуализация» и оговорку, что внешний вид может отличаться.

Коллекции каталога: Sea Mist, Massive Stone, Red Earth.

## Telegram

Кнопки собирает `src/lib/telegram.ts`.

- изделие: `https://t.me/BOT?start=product_PRODUCT_ID`
- коллекция: `start=collection_COLLECTION_ID`
- индивидуальный заказ: `start=custom_order`

В адресе нет имени, телефона и города.

Бот ещё не подключён. Когда появятся имя и токен, диалог на стороне бота такой:

1. Приветствие и модель, коллекция, ориентир цены, фото.
2. Размер или «Помогите определить размер».
3. Имя и контакт.
4. Город.
5. Комментарий.
6. Сводка: отправить, изменить или отменить.
7. Благодарность с явной оговоркой: заявка не подтверждает заказ.

Команда бренда получает сообщение в закрытый чат с номером вида `#LTH-00001`. Повторные заявки нужно отсекать, поля проверять, ошибки Telegram API не показывать как успешную отправку. Маршрут `/api/leads` специально не сделан: сайт не подтверждает заявку, пока это не делает сервер.

## Аналитика

События подготовлены и ничего не отправляют, пока не задан `NEXT_PUBLIC_YANDEX_METRIKA_ID`: `view_home`, `view_collection`, `view_product`, `click_telegram`, `click_custom_order`, `bot_redirect`. Имя и контакт в параметры не входят.
