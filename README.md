# LITHOS

Каталог украшений из натуральных камней. Сайт показывает модели и открывает заявку в Telegram. Оплаты, корзины и оформления заказа на сайте нет.

Рабочее приложение — Next.js в `src/`. Файлы `index.html`, `css/`, `js/` и `assets/` — предыдущий статический прототип брендбука. Их не открывает `npm run dev`.

## Установка и запуск

Нужны Node.js 22 и npm.

```bash
cp .env.example .env.local
npm install
npm run dev
```

Сайт откроется на [http://localhost:3000](http://localhost:3000).

```bash
npm run build
npm start
npm run lint
```

## Переменные

| Переменная | Где используется | Назначение |
| --- | --- | --- |
| `NEXT_PUBLIC_TELEGRAM_BOT_USERNAME` | клиент | Имя бота без `@`. Пока пусто, кнопки не ведут на чужой аккаунт и пишут, что канал ещё не подключён. |
| `NEXT_PUBLIC_SITE_URL` | сервер и метаданные | Канонический адрес для sitemap и Open Graph. |
| `TELEGRAM_BOT_TOKEN` | только сервер | Токен бота от BotFather. В клиентский код не попадает. |
| `TELEGRAM_LEADS_CHAT_ID` | только сервер | Чат, куда бот присылает заявку. |
| `NEXT_PUBLIC_YANDEX_METRIKA_ID` | клиент, после согласия | Счётчик Метрики. Пока переменной нет, события не отправляются. |

## Данные каталога

- Коллекции: `src/data/collections.ts`
- Изделия: `src/data/products.ts`
- Скрытые позиции: `isActive: false`. Они не попадают в каталог, sitemap и страницу модели.
- Цена в данных — ориентир. Перед публикацией замените её на согласованную.
- Фото: `public/images/`. Тип `actual` — реальная съёмка. Тип `concept` показывает бейдж «Концептуальная визуализация» и оговорку, что внешний вид может отличаться.

Коллекции каталога: Sea Mist, Massive Stone, Red Earth.

## Заявка

Форма на страницах изделия, индивидуального заказа и контактов. В ней модель, диаметр руки и ник в Telegram или ВКонтакте. Отправка идёт на `POST /api/leads`. Сервер пишет в Telegram через `sendMessage`. Пока Telegram не ответил успехом, сайт не пишет, что заявка отправлена.

На Render добавьте те же две серверные переменные. Токен берётся у BotFather. Чтобы узнать `TELEGRAM_LEADS_CHAT_ID`, откройте бота и напишите ему любое сообщение, затем откройте `https://api.telegram.org/bot<токен>/getUpdates` и возьмите `message.chat.id`. Это может быть и id группы, если бот добавлен туда.

Пример сообщения:

```
Заявка #LTH-261121-234501
Модель: Sea Mist
Диаметр руки: 16,5 см
Связь: Telegram username
Заявка не подтверждает заказ.
```

## Аналитика

События подготовлены и ничего не отправляют, пока не задан `NEXT_PUBLIC_YANDEX_METRIKA_ID`: `view_home`, `view_collection`, `view_product`, `click_telegram`, `click_custom_order`, `bot_redirect`, `lead_submitted`. Имя и контакт в параметры не входят.
